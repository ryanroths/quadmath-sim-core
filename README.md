# quadmath-sim-core

Real Betaflight 4.5.1, compiled to WebAssembly, flying a first-principles quad
plant at a fixed 1 kHz step, for the quadmath FPV sim.

- Licence: GPL-3.0-or-later. See `LICENSE` and `NOTICE`.
- Toolchain: emsdk 3.1.61, pinned. The committed module must rebuild byte for byte.
- Status and plan: `PROGRESS.md` (append only, newest at the bottom).
